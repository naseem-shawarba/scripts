# scripts

This is a personal collection of simple scripts that I use to automate my daily workflows and repetitive tasks.

## Scripts

### `video-grouper.sh`
A script to organize video files into numbered subdirectories. It takes a single argument to define how many files should be moved into each folder.

#### Usage
1. Make the script executable:
```bash
   chmod +x video-grouper.sh
```
2. Run the script by providing the number of files per folder:

```bash
  ./video-grouper.sh 4
```
Example: If you have 10 videos and run ./video-grouper.sh 4, the script will create 3 folders (1, 2, and 3) and distribute the files accordingly.
